Grafana Dashboards
All Hetu dashboards are auto-provisioned by the kube-prometheus-stack Grafana sidecar: each dashboard ships as a ConfigMap labeled grafana_dashboard:"1", and the sidecar drops them into a single Grafana folder named hetu. The METL set (Metrics · Events · Traces · Logs) covers the four observability pillars over Prometheus, Loki and Tempo.
← All concepts
This is a static design preview — it renders fake-but-realistic data inline and never calls Grafana or any backend. Layout, panel types, units, threshold colors and query expressions mirror the dashboard JSON in deploy/helm/hetu/dashboards/.

Service Map

Service Map / Traces

The interactive service graph and trace search live in the Hetu → LLM Request Traces dashboard and in Explore → Tempo.

Tempo is wired with:

  • tracesToLogs → Loki (jump to logs for a span)
  • tracesToMetrics → Prometheus (request/error rate)
  • serviceMap + nodeGraph (built from span metrics)

Open Explore, pick the Tempo datasource, and use Service Graph to view the live dependency map.
