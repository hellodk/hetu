hetu — feature concepts
Interactive mockups for the new platform features. These are non-functional design samples to review before we build.
⧉

Reusable Resources (Namespace Sync)

Replicate secrets, service accounts, TLS, pull-secrets, configmaps across namespaces via Kyverno generate / Reflector. Drift detection + policy preview.
✉

Email & Alerts (Brevo SMTP)

SMTP settings stored as one secret, distributed by Namespace Sync. Notification rules, delivery health, test send, incident email preview.
⚖

Policies & Governance (Kyverno)

Embed Kyverno PolicyReport / Policy Reporter data: pass/fail, audit→enforce rollout, generate-policies for reusable resources.
❤

Resilience (JVM & Network)

Detect the "restart-to-heal" pattern: OOM/heap headroom, GC, probe vs warm-up, DNS/connect-at-boot. Concrete spec patches.
▦

Observability (Grafana Dashboards)

Auto-provisioned METL + Hetu dashboards in a single "hetu" Grafana folder via the kube-prometheus-stack sidecar. Metrics, Logs, Traces, Events — Prometheus, Loki, Tempo.
