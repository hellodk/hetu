Validation here is wired to real tooling: Kyverno CLI (kyverno apply / kyverno test) for offline rule evaluation, server-side dry-run through the admission webhook (kubectl apply --dry-run=server), and JSON-schema validation against the installed Kyverno CRD. Results are cross-checked against Policy Reporter so the linter and live reports never disagree.
